# Layout rules

- Keep at least 60 px between boxes and 80 px between icons. A crowded diagram is a
  failed diagram.
- An edge must never cross a label or a box title. Put an icon's label on the side the
  edges do not use (right, left or top), align icons on one vertical line for a straight
  flow, and move edge labels along the edge with `<mxGeometry x="-0.6" relative="1">`
  (range -1 to 1).
- Group titles sit top-left. Keep flow lines to the right of the longest title.
- Use all three AZs when the design spans three (subnet in each tier, node per AZ).
- Numbered badges (circles, 40 to 46 px) link icons to a short explanation list.
